# Documentação

Esta pasta reúne as explicações, decisões e anotações de aprendizado do Em Curso.

## Organização inicial

- `../README.md`: apresentação e estado geral do projeto.
- `../client/`: interface que a pessoa acessará pelo navegador.
- `../server/`: código do servidor, responsável por validar operações e acessar dados e serviços.

As pastas serão preenchidas gradualmente. A estrutura inicial não define bibliotecas nem banco de dados.
